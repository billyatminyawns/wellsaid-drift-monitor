Help Article
Fix preview
Current
Open ID Connect (OIDC)
Fix
Restore the OpenID Connect values that were replaced with duplicated SAML values during the July 31 rewrite. Under "Open ID Connect (OIDC)", the values your technical contact provides are Issuer URL, Client ID, and Provider domain (example: wellsaid.io) — not a SAML sign-in URL or an X.509 signing certificate. An Enterprise IT team setting up OIDC has nothing correct to work from, and every value on the page points them at a SAML connection instead. The four OIDC-specific values (Issuer URL, Client ID, Redirect URL, Initiative login URL) were published on this page as recently as the July 26 scan and disappeared in the July 31 rewrite.
